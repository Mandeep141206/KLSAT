# KLSAT - Kali Linux Security Assessment Toolkit

KLSAT (Kali Linux Security Assessment Toolkit) is a Bash-based cybersecurity toolkit designed to automate basic Linux security assessment and auditing tasks.

# Features

- System Information
- Network Information
- Port Scanning
- Process Monitoring
- Log Analysis
- File Permission Scanning
- Hash Generation
- Security Reporting

## Technologies Used

- Kali Linux
- Bash Shell Scripting
- Nmap
- Linux Command Line
- Git
- GitHub
- HTML

## Objective

- The main objective of KLSAT is to combine multiple Linux security assessment tasks into a single interactive toolkit.Instead of manually executing multiple commands, users can select security modules from the toolkit menu.
